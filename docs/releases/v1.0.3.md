# 净屏 v1.0.3 (versionCode 4) · 规则兼容性改进

本版本继续只做 DNS 网络过滤。没有无障碍服务、自动点击、默认链接接管、Root、CA 安装或 HTTPS 解密。

- 随包加入官方完整 [AdGuard DNS filter](https://adguardteam.github.io/AdGuardSDNSFilter/Filters/filter.txt)，首次安装后可离线使用。规则不会自动联网更新；需要时由用户手动启动官方订阅更新。
- “规则来源与开关”可分别启用或停用 AdGuard DNS 和 anti-AD。AdGuard DNS 导入支持纯域名行、`||domain^`、`*.domain`、`@@` 例外以及 `$important`、`$badfilter`。AdGuard 导入不会解析 hosts 地址行；hosts 文件请使用独立的“导入域名 / hosts 规则”功能。
- 导入 AdGuard DNS 列表只执行解析器支持的 DNS 规则，并显示可执行与忽略数量。含不支持修饰符的规则行整体忽略；网址路径、正则、CSS 和 JS 规则也会整体忽略，不会剥除修饰符或转换成其他规则。当前随包快照解析出 187,396 条可执行规则、忽略 940 条；更新后的数量可能变化。
- 增加对 DNS 响应中 CNAME answer chain 的逐跳检查；若链中的目标域名命中启用的拦截规则，可拒绝原始查询。
- 应用代码为 MIT；随包完整 AdGuard DNS 数据采用 GPL-3.0，并随 APK 包含完整许可文本。其他第三方规则的来源和许可见[第三方说明](https://github.com/an-stu/CiviAdShield/blob/v1.0.3/THIRD_PARTY_NOTICES.md)。

## 百度贴吧范围

在官方贴吧 22.13.1.1 的 Android 15 ARM64 公开帖子详情滚动测试中，未过滤基线曾看到明确标注的 50 元红包悬浮广告。随后同一帖子在过滤样本和关闭过滤后的再次复查中都没有该悬浮广告，现有观察无法证明它是由过滤移除。过滤期间商业/优惠类回复和配图仍然可见。

DNS 不能区分同一域名或接口中的广告与正常内容。AdGuard 中文 13 贴吧网页规则中的 CSS/DOM 选择器不能作用于原生 Android 应用；本版本没有完成 AdGuard Android 应用的完整对比，也没有注册试用。当前结果不支持“贴吧原生信息流广告已被完整移除”的结论。详细方法与证据边界见[贴吧实测](https://github.com/an-stu/CiviAdShield/blob/v1.0.3/docs/TIEBA.md)。

Android 15/16 ARM64 模拟器分别通过 25 项界面/网络检查和 27 项 Release 仪器检查；Java 单元测试 40 项、Python 工具测试 20 项通过。没有小米真机覆盖。[验证记录](https://github.com/an-stu/CiviAdShield/blob/v1.0.3/VALIDATION.md) · [权限说明](https://github.com/an-stu/CiviAdShield/blob/v1.0.3/PERMISSIONS.md)
