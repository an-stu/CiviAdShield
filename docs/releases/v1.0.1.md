# 净屏 v1.0.1

免 Root Android 应用，最低 Android 8.0。广告域名拦截使用本地 VPN，无障碍仅用于可选的开屏自动跳过。

本版本修复：

- 暂停时显式关闭 VPN 通道，避免系统保持服务绑定后占用 VPN。
- 隔离每次 VPN 运行，避免旧读线程、旧任务干扰重新建立的连接。
- 应用选择界面选择后收起键盘，修复保存按钮遮挡。

已在 Android 15 ARM64 模拟器进行 35 项端到端检查、24 项仪器检查，另有 23 项协议/规则单元测试。HyperOS 3.0.303.0 的后台行为与第三方商业应用广告覆盖率仍需真机验证。

[权限说明](https://github.com/an-stu/CiviAdShield/blob/v1.0.1/PERMISSIONS.md) · [验证报告与截图](https://github.com/an-stu/CiviAdShield/blob/v1.0.1/VALIDATION.md)

使用 Clash Meta 时暂停净屏的本地 VPN；可将导出的域名规则交由 Clash 执行。开屏跳过可独立使用。与正常内容共用域名/接口的嵌入广告可能无法拦截。
