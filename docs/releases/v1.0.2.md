# 净屏 v1.0.2 · 网络拦截版

面向小米、Redmi、POCO 的 Android 8.0+ 通用客户端，沿用原签名，可覆盖升级。

- 移除无障碍服务与自动点击功能，不接管默认浏览器；只做网络域名阻断。
- 新增“仅拦截指定应用”，与排除列表互斥；指定应用全部不可用时明确停止，选择界面能清理已卸载项。
- 泛化 MIUI / HyperOS 后台设置说明、标准应用信息/省电入口、设备及 Android 版本信息。
- 调整系统栏 Insets 与滚动区域，避免交互区域落入导航栏。
- 真实安装官方贴吧 22.13.1.1：仅过滤贴吧、无障碍关闭时，启动到进入公开“小米吧”记录到 84 次广告/跟踪 DNS 请求被阻断，普通帖子和图片仍能加载。请求包含重试，不等于广告数量。
- 扩展 Android 15 / 16 ARM64 模拟器和协议检查；没有小米真机覆盖，也未验证所有系统/机型。

**边界：** 基线和过滤样本均未采集到明确广告卡片，不能据此宣称贴吧信息流广告全部去除；真实广告点击跳转未取得可重复样本。DNS 不能全局禁止其他应用显式拉起应用，也不能分离同域接口内的广告与正常内容。
