# 百度贴吧实际测试

真实官方贴吧测试，结果只覆盖实际执行的公开内容样本。投放和网络条件会影响广告显示。本页不包含用户名、帖子 ID、原始截图或界面树。

## 应用与环境

- 官方入口：https://c.tieba.baidu.com/c/s/download/pc?src=webtbGF
- 包名 `com.baidu.tieba`，版本 `22.13.1.1`，versionCode `369950981`，ARM64。
- APK SHA256：`98545203220765504f8f23b55dd32fb49c1c5cef06ae80f0e83f533687a9106e`。
- AOSP Android 15 / API35 ARM64 模拟器，1080×2400，模拟蜂窝网络；宿主网络的 DNS A 记录使用 `198.18.0.0/16` 合成地址。
- 净屏通过 Android per-app VPN 仅处理贴吧；系统无障碍保持关闭。测试访问公开内容，不登录账号，也不在贴吧输入电话、密码或验证信息。

## DNS 请求观察（2026-11-03）

此前公开吧页网络样本的基线抓到 59 次命中内置广告/跟踪列表的 UDP DNS 查询。仅过滤贴吧时，本机计数由 16 增至 100，记录 84 次被阻断；过滤期间外部抓包未见命中该列表的 UDP DNS 查询外发。普通帖子和图片仍能加载。

84 次包含重试和跟踪请求，不能解释为广告数量。两段抓包的采样时长与初始化状态不同，不能据此计算拦截率或证明可见广告被移除。该次 DNS 统计摘要见 [summary.json](tieba-tests/2026-11-03/summary.json)。

## 帖子详情观察（2026-11-04）

滚动查看公开帖子详情时，未过滤基线曾出现清楚标注的 50 元红包悬浮广告。开启仅过滤贴吧后复查同一公开帖子，该悬浮广告没有出现；随后关闭过滤再次查看时，它仍没有出现。因此这组观察无法确认它的消失由 DNS 过滤导致。

过滤期间，商业/优惠类回复及配图仍可见。DNS 过滤无法按内容类型区分同一域名或接口返回的商业回复与正常内容，也无法删除缓存或客户端已绘制的卡片。没有重复、受控的广告点击样本，因此没有验证点击后的跳转。

AdGuard 中文 13 贴吧规则中的 CSS/网页元素选择器针对网页 DOM，不会在贴吧原生 Android 界面上运行，也不能靠 DNS 过滤执行。没有完成 AdGuard Android 应用的完整对比；本次没有注册试用。

## 结论边界

真实贴吧的部分广告/跟踪 DNS 请求能够被本地拒绝，公开页面中的帖子和图片在此前样本中仍可加载。当前证据不能证明 DNS 过滤移除了悬浮广告、贴吧原生信息流广告已全部去除，或广告点击跳转已全部阻止。

本测试在 AOSP Android 15 ARM64 模拟器完成，没有小米真机覆盖，也未覆盖登录后推荐内容、所有广告投放或所有 MIUI/HyperOS 版本。兼容范围见 [COMPATIBILITY.md](COMPATIBILITY.md)。
