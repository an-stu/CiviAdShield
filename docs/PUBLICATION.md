# 公开仓库说明

2026-11-03 按仓库所有者要求将 `an-stu/CiviAdShield` 由私有转为公开。

公开前检查了当时可达历史（3 个提交、130 个历史路径）：没有发现签名文件、私钥、签名口令文件、GitHub token、AWS 访问密钥或环境文件进入 Git。日志中 `token` 字段经复核属于 Android Binder/窗口对象与空值；网络探针的 token 是测试结果标签，不是认证凭据。脚本中的口令由本机动态生成，未把生成值写入 Git。

历史截图与日志来自未登录个人账号的自建 AOSP 测试环境。真实贴吧的后续 APK、原始 PCAP、完整帖子截图、完整日志和未经脱敏网络材料保留在忽略的 `.toolchain/`，公开仓库只保留无账号/帖子内容的数据摘要。

签名私钥保留于本机忽略目录及加密的 GitHub Actions Secrets，供可信主分支签名构建；不进入源码包或 Release。Pull Request 检查不访问签名 Secrets，签名/发布任务只在本仓库主分支运行。

公开下载版本的 APK、SHA256 和公共签名证书指纹可核验。相同版本的 Release 不被后续普通提交覆盖，提高版本号后才自动创建新 Release。
